# HospLink


## 📱 About The App

**HospLink** is a Flutter-based healthcare platform that connects patients with hospitals through a unified digital experience. The application allows patients to discover hospitals, submit medical requests, track request status, communicate with hospitals, and manage their medical history, while hospitals can review and manage incoming patient requests efficiently.

## 🏗️ Architecture

The project follows **Clean Architecture** with a **Feature-Based Structure**, separating Presentation, Domain, and Data layers to ensure scalability, maintainability, and testability.

---

## 🛠️ Tech Stack

### Core Technologies

* Flutter
* Dart
* Firebase Authentication
* Cloud Firestore

### Architecture & State Management

* Flutter Bloc
* GetIt
* GoRouter

### Additional Tools

* Shared Preferences

* Flutter ScreenUtil

* Flutter SVG

## 🔥 Technical Highlights

* Real-time hospital and patient data synchronization using Cloud Firestore.
* Feature-based Clean Architecture with clear separation of concerns.
* State management powered by Flutter Bloc.
* Role-based user experience for Patients and Hospitals.
* Responsive UI optimized for different screen sizes.
